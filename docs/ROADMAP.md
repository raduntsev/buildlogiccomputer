# План доработки Logic Lab 3.5

Источник: ТЗ автора (пункты 1–30). Работа разбита на небольшие этапы, каждый помещается в одну сессию и не ломает сборки web / Electron / Android / Neutralino.
После правок в `src/` всегда: `python build.py`, затем `cp dist/offline.html web/index.html` и `cp dist/offline.html downloads/LogicLab-3.5.html`. Бинарные сборки (`.exe`, `.zip`, `.apk`) пересобираются отдельно, по README.

Статус: ✅ сделано · ⏳ следующий · ☐ в очереди
